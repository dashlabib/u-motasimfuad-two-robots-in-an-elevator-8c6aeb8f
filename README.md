One line of awkward small talk that one robot says to another while riding an elevator together — a robot that ran the ride through simulation twelve times and still blew the landing.

> "I simulated this elevator ride twelve times, and in every version I still end up saying something weird. Like this. Right now. Sorry."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
